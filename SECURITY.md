# Security Policy

This repo powers [robertritacca.com](https://robertritacca.com/) and its design system. If you find a security issue — in the site, the components, or the dependency chain — I'd like to hear about it.

## Reporting a vulnerability

- **Preferred:** [open a private vulnerability report](https://github.com/robritacca-dotcom/design-system/security/advisories/new) — it stays between us until a fix ships.
- Please don't open a public issue for security problems.

You can expect a response within a few days. This is a personal portfolio project, not a distributed package, so there are no supported-version tables — `main` is what's live.
