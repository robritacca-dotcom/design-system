# robr0 Design System

A token-driven design system built from Figma variables, shipped as CSS custom properties with React components. Everything flows from a single source of truth: **Figma &rarr; Primitives &rarr; Semantic Tokens &rarr; Components &rarr; Website**.

</div>

<div className="ds-section">

## Architecture

<div className="ds-arch-grid">
  <div className="ds-arch-card">
    <div className="ds-arch-number">1</div>
    <h4>Figma Variables</h4>
    <p>Colour, Mode, and Spatial collections defined in Figma. Primitives are raw hex/rgba values. Mode tokens map primitives to light and dark themes.</p>
  </div>
  <div className="ds-arch-card">
    <div className="ds-arch-number">2</div>
    <h4>CSS Primitives</h4>
    <p>tokens-primitives.css — the raw scale. Neutral 00–11, plus Red, Orange, Yellow, Green, Teal, Blue, Purple. Semi-transparent variants for glass effects. Never used directly in components.</p>
  </div>
  <div className="ds-arch-card">
    <div className="ds-arch-number">3</div>
    <h4>Semantic Tokens</h4>
    <p>tokens-light.css and tokens-dark.css map primitives to purpose: text, icon, background, action, and status colours. Components only reference these.</p>
  </div>
  <div className="ds-arch-card">
    <div className="ds-arch-number">4</div>
    <h4>Components</h4>
    <p>{"React components consume semantic tokens via var(--token). Button, ButtonGroup, Card, Nav, ToggleSwitch — all theme-aware out of the box."}</p>
  </div>
  <div className="ds-arch-card">
    <div className="ds-arch-number">5</div>
    <h4>Website</h4>
    <p>{"Next.js site imports tokens.css once in the layout. Components are used directly. Theme switching via data-theme attribute on the root element."}</p>
  </div>
</div>

</div>

## Token Layers

<div className="ds-token-flow">
  <div className="ds-flow-step">
    <strong>tokens-primitives.css</strong>
    <span>{"Raw values on :root"}</span>
  </div>
  <div className="ds-flow-arrow">&rarr;</div>
  <div className="ds-flow-step">
    <strong>tokens-typography.css</strong>
    <span>Font families, sizes, weights</span>
  </div>
  <div className="ds-flow-arrow">&rarr;</div>
  <div className="ds-flow-step">
    <strong>tokens-light.css</strong>
    <span>{"[data-theme=\"light\"], :root"}</span>
  </div>
  <div className="ds-flow-arrow">&rarr;</div>
  <div className="ds-flow-step">
    <strong>tokens-dark.css</strong>
    <span>{"[data-theme=\"dark\"] overrides"}</span>
  </div>
</div>

Import order matters. The single entry point is **tokens.css** which imports all four files in the correct cascade.

</div>

## Theming

The system uses a **data-theme** attribute on the document root. Storybook mirrors this with the theme switcher in the toolbar.

<div className="ds-theme-grid">
  <div className="ds-theme-card ds-theme-light">

    <div className="ds-theme-swatch" style={{ background: '#0E0E0E', color: '#F1F1F1' }}><span>#0E0E0E</span></div>

  </div>
</div>

Passive/action tokens use **semi-transparent rgba values** so components like Button and Card get natural glass-like effects when layered over backgrounds with backdrop blur.

</div>
